# Roadmap Reku

План по итогам ревью кода (сентябрь 2026). Фазы идут по порядку, внутри фазы пункты
независимы. Отмечай сделанное `[x]` в том же коммите, где сделана работа.

Метка **[железо]** — пункт нельзя закрыть в облаке или на CI: нужна ручная проверка на
Windows с реальным GPU/микрофоном/клавиатурой (чек-лист в конце).

## Фаза 0 — быстрые исправления

### Ядро (`reku/dictate.py`)
- [x] Хоткей не работает, если первая загрузка модели упала: слушатель клавиш запускается
      только после успешной загрузки, `reload_model()` его не запускает, а повторить
      загрузку можно лишь сменой модели в настройках. Слушатель — сразу при старте;
      нажатие хоткея или «Записи» без модели запускает повторную загрузку.
- [x] Колбэки pynput выполняются в потоке низкоуровневого хука клавиатуры, а `start_rec()`
      там же синхронно открывает аудиопоток (при ошибке ещё и переинициализирует PortAudio).
      Это лаг ввода во всей системе и риск, что Windows молча снимет хук
      (`LowLevelHooksTimeout`). Колбэк только ставит команду в очередь, команды выполняет
      один рабочий поток.
- [ ] Утечка памяти: процесс в трее дорастает до ~2.7 ГБ RSS за пару суток (issue #19).
      Снимать `tracemalloc`-снимки по времени; подозреваемые — пересоздание аудиопотоков
      и PortAudio, кэши движка на входах разной длины (OpenVINO), объекты Qt при
      перерисовке. **[железо]**: воспроизвести на долгом аптайме.

## Что уже известно

- **Бенчмарк ASR (август 2026)**, живая запись 109 с — быстрая русская речь с английскими
  терминами. Лучший результат: vanilla `large-v2` + двуязычный `initial_prompt`
  (инструкция «English terms are preserved in Latin script» с примером). `large-v3` на
  code-switching хуже `v2` даже с тем же промптом; `large-v3-turbo` в ~3 раза быстрее, но
  теряет часть терминов; русские файнтюны Whisper пишут термины кириллицей; модели без
  промпта и hotwords (GigaAM-v3, Parakeet-TDT-v3, Canary-1B-v2) проигрывают на терминах
  прежде всего из-за отсутствия биасинга. Выборка — одна запись: вывод предварительный.
- **Латиница внутри русских слов** шла от латинского `initial_prompt`; лечится
  `language="ru"` + русский или двуязычный промпт, термины — в `hotwords`.
  `no_repeat_ngram_size > 0` коверкает легитимные повторы слов — выключен по умолчанию.
- **AMD (июль 2026)**: выбран whisper.cpp + Vulkan (свой CI-билд). ROCm для CTranslate2 на
  Windows сырой (рассинхрон версий колёс и HIP SDK), DirectML в режиме поддержки,
  Windows ML не поддерживает GenAI на AMD. Пересмотреть ROCm в 2027.
- **HF offline-флаги**: у части пользователей `TRANSFORMERS_OFFLINE`/`HF_HUB_OFFLINE`
  прописаны в реестре глобально и ломают первое скачивание — приложение снимает их при
  старте.
- **Не-ASCII путь профиля**: elevated PowerShell получает `%TEMP%` коротким 8.3-путём —
  `install.ps1` строит временный каталог от `%LOCALAPPDATA%`. OpenVINO с не-ASCII путём к
  моделям — отдельно не проверялся.
